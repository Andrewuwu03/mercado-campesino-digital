# Mercado Campesino Digital de Yopal

Proyecto académico para publicar ofertas semanales de productos agrícolas y pecuarios, gestionar reservas anticipadas y consultar reportes.

## Alcance
- Registro e inicio de sesión por roles.
- Perfil de productores y vereda.
- Publicación y consulta de ofertas.
- Reservas hasta el viernes a las 6:00 p. m.
- Validación de inventario.
- Reportes por producto, productor y vereda.

Los pagos son contra entrega en efectivo o Nequi. No se procesan pagos en línea. Los domicilios y la aplicación móvil nativa quedan fuera de la primera versión.

## Estructura
- `docs/`: arquitectura, requisitos, modelo de datos, casos de prueba y diagramas.
- `backend/`: ejemplo Java de validación y prueba unitaria.
- `frontend/`: maqueta web HTML, CSS y JavaScript.

## Importante
Esta es una base académica inicial, no una aplicación completa. El ejemplo Java todavía no incluye API REST, persistencia, autenticación real ni transacciones de base de datos. Las pruebas deben ejecutarse y documentarse antes de afirmar que pasaron. La página web es una maqueta y no registra reservas reales.

No subas contraseñas reales, claves, tokens ni datos personales.
